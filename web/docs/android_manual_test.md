# 安卓 QQ 浏览器局域网验收参考

## 访问前准备

- 电脑和手机连接同一 Wi-Fi。
- 使用电脑当前 WLAN IPv4：`<WLAN_IPV4>`。
- 手机 URL：`http://<WLAN_IPV4>:4173/`。
- 前台 Node 服务运行期间保持终端打开；结束时使用 `Ctrl+C`。

如果 Wi-Fi 重连后打不开，先在电脑运行 `ipconfig`，把 URL 中的 IP 替换为 WLAN 的新 IPv4。若 Windows 防火墙提示，手工允许 Node.js 访问“专用网络”即可；不要开放公用网络，也不要全局关闭防火墙。

## 操作步骤

1. 安卓 QQ 浏览器打开 `http://<WLAN_IPV4>:4173/`。
2. 在“浏览器与设备”区记录 `protocol`、`isSecureContext`、`cryptoRandomUUID` 与 `cryptoGetRandomValues`。普通局域网 HTTP 可预期为 `http:`、`false`、`undefined`、`function`；这是兼容层需要覆盖的正常环境。
3. 点击“选择真实截图或文字 ROI”，选择一张本机星石图片；不要选择需要保密且不愿保存在浏览器站点数据中的图片。
4. 点击“加载并验证模型”，记录首次完成时间；再刷新页面重复一次，记录缓存后时间。
5. 点击“开始本地 OCR”，确认不再出现 `crypto.randomUUID is not a function`，并记录是否卡死、崩溃、系统杀页、发热明显或长时间无响应。
6. 核对原始文本、置信度和框是否覆盖目标文字。
7. 点击“保存到 IndexedDB”，刷新页面，再点击“从 IndexedDB 恢复”；确认原图和 OCR JSON 都恢复。
8. 点击“导出本地备份 JSON”，确认 QQ 浏览器下载列表出现 JSON 文件。
9. 点击“删除 IndexedDB 记录”，确认无法恢复；再用“导入备份 JSON”选择刚导出的文件，确认图片和结果恢复。
10. 点击“刷新摘要”，确认 `containsUserDataCount = 0`。若存在外部请求，记录 URL 并区分浏览器环境注入脚本与 YuanStar 应用请求；不要要求整个浏览器环境 `externalRequestCount = 0`。
11. 可选：在 QQ 浏览器站点设置中清除此站点数据，确认 IndexedDB 记录随站点数据删除；这是预期边界。

## 本轮已完成结果摘要

来源：用户在实体 Android 设备上的本轮人工验收结果，Codex 未在实体手机上自动执行。

- 辅星完整页识别结果与电脑端一致，运行期间无崩溃。
- 经验星曜橙/紫/白三类型页运行成功，无崩溃。
- 主星 smoke、辅星与经验星曜三个入口的状态隔离均正常。
- 窄屏页面可回落、可操作；本调试页面不要求独立移动端视觉设计。
- 当前结论：本阶段 Android 功能验收通过；不代表正式产品 UI 已接入。

保留的已知缺口：经验星曜生产 `tab_ocr` 页面文字回退尚未迁移；本轮没有迁移经验值换算、升级需求或库存抵扣。

## 已知容器边界

“出境易”中的 Chrome 可以打开本页面，但其文件选择器未能拉起。这是第三方容器/应用包装环境的文件选择器或系统权限交接兼容问题，不是 OCR、模型或 IndexedDB 的结论。本轮核心验收请使用已能正常选择文件并加载模型的 QQ 浏览器；不要据此声称所有安卓 Chrome 环境都支持文件选择。
